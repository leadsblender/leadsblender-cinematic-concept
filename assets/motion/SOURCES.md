# Atmospheric hero film

`hero-loop.mp4` is an image-to-video animation derived from the already approved `../v3/hero.webp`, generated through the authenticated Higgsfield MCP connector with `kling4_0`.

- Accepted generation: `4502fcac-fb4f-42db-a4ea-d7e4d9a1f931`.
- Input: the existing hero image, not a new sky design.
- Direction: a locked-off camera with evolving cloud edges; retain the midnight/aqua palette and horizon. No parallax, new objects, UI or foreground cloud overlays.
- Local delivery: scaled to 1920px wide, forward/reverse ambient loop, slowed slightly, H.264/yuv420p with fast-start metadata. Audio is removed entirely.
- The initial test generation (`df2d2bc4-69dc-49b1-9020-0478f3025365`) was rejected because identical first/last references produced an almost static video. It is not shipped.
- This is generated atmospheric illustration, not a product recording or proof of an enabled feature.

The five original scene images remain byte-for-byte unchanged. The original hero image is also the no-video/reduced-motion poster. The film plays independently of scrolling, pauses when offscreen or hidden, and has an explicit pause control.
