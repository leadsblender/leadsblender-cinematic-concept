# LeadsBlender · Cinematic concept

Independent design study of the supplied Digital Archive sample, adapted to LeadsBlender's dark / white / electric-aqua identity. The exact sample was rendered and visually reviewed before this revision. This repo is a preview and does **not** replace `trial.leadsblender.com`.

## Chapters

1. Full-viewport painterly-cloud hero, glass navigation and overlapping cloud transitions.
2. AI Studio as the lead product story, followed by its build/edit/publish capabilities.
3. Workflow AI Builder and the customer journey.
4. Claude via HighLevel MCP, and OpenAI/Anthropic model selection in a Workflow AI Agent action — these are distinct routes.
5. The wider HighLevel AI family: Ask AI, Conversation AI, Voice AI, Managed Agents, Agent Studio, Content & Email AI, Reviews AI and Knowledge Base.
6. Selling through AI Studio Payments **or** a classic funnel order form; Q&A; closing invitation.

Six original scenes/cutouts were generated through the authenticated Higgsfield MCP connector. Their optimized WebP versions are committed in `assets/v3/`. The hero uses a subtle CSS camera push over a **still image**, not a generated video. Typography uses Instrument Serif and Montserrat from Google Fonts. Scroll reveals honor reduced-motion settings.

Product descriptions are based on the official HighLevel support articles linked under **Productbronnen** in the page footer. This is a concept, not proof that these integrations or checkout paths are enabled in a particular LeadsBlender account. Model access, permissions, supported payment types and usage charges require configuration and validation. The CTA links to the verified `https://trial.leadsblender.com/` homepage, not a fictional checkout.
