# LeadsBlender · Cinematic concept

Independent design study based on the supplied editorial full-screen reference, adapted to the existing LeadsBlender black / white / electric-aqua palette. This does not replace trial.leadsblender.com.

- Three original scenes generated via the authenticated Higgsfield MCP connector using `gpt_image_2_5`; copied into `assets/` to keep the preview stable. Total preflight image cost: 0.75 credits.
- The hero uses a subtle CSS camera push over a still, **not a generated video**. A 5-second Seedance video preflight was 35 credits, so no video was ordered.
- Type: Instrument Serif for editorial display and Montserrat for brand/UI. Google Fonts are loaded from the network.
- The final CTA links to the existing trial checkout at `https://trial.leadsblender.com/checkout`; this preview has no lead form or checkout of its own.
- Layout tested in Chrome/Playwright at 1440×900 and 390×844: all three assets loaded, no script errors, no horizontal overflow, every scroll reveal appeared.

Open `index.html` in a browser, or use the GitHub Pages preview. Concept copy and visual direction need brand approval before production use.
